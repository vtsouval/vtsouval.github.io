# Profile brand assets

## alphaXiv

Source: [official alphaXiv site](https://www.alphaxiv.org/), logo in its main navigation, retrieved 14 October 2026.

- `alphaxiv-source.svg`: original vector markup; geometry retained without tracing or rasterization.
- `alphaxiv.svg`: standalone SVG that follows the system colour scheme.
- `alphaxiv-light.svg` / `alphaxiv-dark.svg`: explicit variants for light / dark backgrounds.
- `../icons.svg#alphaxiv`: reusable `currentColor` symbol for the website. Its inline geometry follows the active page theme and link hover/focus colours.

The mark identifies and links to alphaXiv. The brand remains the property of its owner; these files do not imply endorsement or a new licence for the mark.
